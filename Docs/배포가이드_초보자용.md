## 1. 사전 준비사항

### 필요한 것들
- AWS 계정 (무료 티어 사용 가능)
- 로컬 컴퓨터에 설치된 것들:
  - Docker Desktop (또는 Docker Engine)
  - Git
  - Java 17 (백엔드 빌드용)
  - Python 3.9+ (AI 모듈 빌드용, 선택사항)
  - SSH 클라이언트 (Windows는 PuTTY 또는 Git Bash)

### AWS 계정 생성
1. [AWS 공식 사이트](https://aws.amazon.com/) 접속
2. "계정 만들기" 클릭
3. 신용카드 등록 (무료 티어 사용 시에도 필요하지만 실제 과금은 안 됨)
4. 이메일 인증 완료

## 2. AWS EC2 인스턴스 생성

### 2-1. EC2 대시보드 접속
1. AWS 콘솔에 로그인
2. 검색창에 "EC2" 입력 후 선택
3. 왼쪽 메뉴에서 "인스턴스" 클릭

### 2-2. 인스턴스 시작
1. "인스턴스 시작" 버튼 클릭

### 2-3. 인스턴스 설정
**이름 및 태그:**
- 이름: `caffit-server` (원하는 이름)

**애플리케이션 및 OS 이미지:**
- Amazon Linux 2023 선택 (무료 티어)

**인스턴스 유형:**
- t2.micro 선택 (무료 티어, 1년간 무료)

**키 페어(로그인):**
- "새 키 페어 생성" 클릭
- 키 페어 이름: `caffit-key`
- 키 페어 유형: RSA
- 프라이빗 키 파일 형식: .pem
- "키 페어 생성" 클릭
- **중요**: 다운로드된 `.pem` 파일을 안전한 곳에 보관! (다시 다운로드 불가능)

**네트워크 설정:**
- "보안 그룹 규칙 편집" 클릭
- 인바운드 규칙 추가:
  - SSH (포트 22): 내 IP
  - HTTP (포트 80): 어디서나 (0.0.0.0/0)
  - 사용자 지정 TCP (포트 8080): 어디서나 (0.0.0.0/0) - 백엔드용
  - 사용자 지정 TCP (포트 5001): 어디서나 (0.0.0.0/0) - AI 모듈용

**스토리지:**
- 기본값 (8GB) 유지

### 2-4. 인스턴스 시작
1. "인스턴스 시작" 버튼 클릭
2. 잠시 후 인스턴스 목록에서 상태가 "실행 중"이 될 때까지 대기
3. 인스턴스 선택 후 "퍼블릭 IPv4 주소" 복사 (예: `3.34.123.45`)

## 3. EC2 환경 설정

### 3-1. EC2에 접속하기

**Windows (Git Bash 또는 PowerShell):**
```bash
# .pem 파일 권한 설정 (Git Bash)
chmod 400 caffit-key.pem

# SSH 접속
ssh -i caffit-key.pem ec2-user@<퍼블릭-IP-주소>
```

**Mac/Linux:**
```bash
# .pem 파일 권한 설정
chmod 400 caffit-key.pem

# SSH 접속
ssh -i caffit-key.pem ec2-user@<퍼블릭-IP-주소>
```

**Windows (PuTTY 사용 시):**
1. PuTTYgen으로 .pem 파일을 .ppk로 변환
2. PuTTY에서 호스트 이름: `ec2-user@<퍼블릭-IP-주소>`
3. Connection > SSH > Auth에서 변환한 .ppk 파일 선택

### 3-2. Docker 설치
EC2에 접속한 후 다음 명령어 실행:

```bash
# 시스템 업데이트
sudo yum update -y

# Docker 설치
sudo yum install docker -y

# Docker 서비스 시작
sudo systemctl start docker
sudo systemctl enable docker

# ec2-user를 docker 그룹에 추가 (sudo 없이 docker 사용)
sudo usermod -aG docker ec2-user

# 설치 확인
docker --version
```

**중요**: Docker 그룹 추가 후 다시 로그인해야 적용됩니다.
```bash
exit
# 다시 SSH 접속
ssh -i caffit-key.pem ec2-user@<퍼블릭-IP-주소>
```

## 4. MySQL 데이터베이스 설정

### 옵션 A: EC2에 직접 설치 (간단함)

```bash
# MySQL 설치
sudo yum install mysql-server -y

# MySQL 서비스 시작
sudo systemctl start mysqld
sudo systemctl enable mysqld

# MySQL 보안 설정
sudo mysql_secure_installation
# 비밀번호 설정 (기억해두세요!)

# MySQL 접속
mysql -u root -p

# 데이터베이스 생성
CREATE DATABASE caffit CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 사용자 생성 및 권한 부여
CREATE USER 'caffit_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON caffit.* TO 'caffit_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 옵션 B: AWS RDS 사용 (더 안정적, 유료)

1. AWS 콘솔에서 "RDS" 검색
2. "데이터베이스 생성" 클릭
3. MySQL 선택
4. 템플릿: 무료 티어
5. 데이터베이스 식별자: `caffit-db`
6. 마스터 사용자 이름/비밀번호 설정
7. 퍼블릭 액세스: 예
8. VPC 보안 그룹: 새로 생성 또는 기존 EC2 보안 그룹 선택
9. "데이터베이스 생성" 클릭
10. 생성 완료 후 엔드포인트 주소 확인

## 5. 로컬에서 Docker 이미지 빌드

### 5-1. 프로젝트 클론 (아직 안 했다면)
```bash
git clone <your-repository-url>
cd 2025-2-OSSProj-semicolon-02
```

**Windows (PowerShell 또는 Git Bash):**
```bash
cd backend

# Gradle 빌드
.\gradlew.bat build -x test

# Docker 이미지 빌드
docker build --platform=linux/amd64 -t caffit-backend .
```

**Mac/Linux:**
```bash
cd backend

# Gradle 빌드
./gradlew build -x test

# Docker 이미지 빌드
docker build --platform=linux/amd64 -t caffit-backend .

# 이미지를 tar 파일로 저장
docker save caffit-backend > caffit-backend.tar
```

```bash
cd ../AI_model

docker build --platform=linux/amd64 -t caffit-ai .

# 이미지를 tar 파일로 저장
```

## 6. EC2에 배포하기

### 6-1. 이미지 파일을 EC2로 전송

**Windows (PowerShell 또는 Git Bash):**
```bash
# 백엔드 이미지 전송
scp -i caffit-key.pem backend/caffit-backend.tar ec2-user@<퍼블릭-IP-주소>:~/

# AI 모듈 이미지 전송
scp -i caffit-key.pem AI_model/caffit-ai.tar ec2-user@<퍼블릭-IP-주소>:~/
```

**Mac/Linux:**
```bash
# 백엔드 이미지 전송
scp -i caffit-key.pem backend/caffit-backend.tar ec2-user@<퍼블릭-IP-주소>:~/

# AI 모듈 이미지 전송
scp -i caffit-key.pem AI_model/caffit-ai.tar ec2-user@<퍼블릭-IP-주소>:~/
```

### 6-2. EC2에서 이미지 로드 및 컨테이너 실행

EC2에 SSH 접속 후:

```bash
# 백엔드 이미지 로드
docker load < caffit-backend.tar

# AI 모듈 이미지 로드
docker load < caffit-ai.tar

# 이미지 확인
docker images
```

### 6-3. 환경 변수 준비

EC2에서 환경 변수 파일 생성 (선택사항, 또는 docker run 명령에 직접 입력):

```bash
# .env 파일 생성 (선택사항)
nano backend.env
```

다음 내용 입력 (실제 값으로 변경):
```
DB_URL=jdbc:mysql://localhost:3306/caffit
DB_USER=caffit_user
DB_PASSWORD=your_password
KAKAO_REST_API_KEY=your_kakao_key
```

저장: `Ctrl + X`, `Y`, `Enter`

### 6-4. 백엔드 컨테이너 실행

```bash
docker run -d -p 8080:8080 \
  -e DB_URL=jdbc:mysql://localhost:3306/caffit \
  -e DB_USER=caffit_user \
  -e DB_PASSWORD=your_password \
  -e KAKAO_REST_API_KEY=your_kakao_key \
  --name caffit-backend caffit-backend
```

또는 환경 변수 파일 사용:
```bash
docker run -d -p 8080:8080 --env-file backend.env --name caffit-backend caffit-backend
```

### 6-5. AI 모듈 컨테이너 실행

```bash
docker run -d -p 5001:5001 \
  -e OPENAI_API_KEY=your_openai_key \
  -e DB_URL=jdbc:mysql://host.docker.internal:3306/caffit \
  --name caffit-ai caffit-ai
```

**참고**: 컨테이너에서 호스트 MySQL에 접속하려면 `host.docker.internal` 대신 EC2의 내부 IP를 사용하거나, 네트워크를 공유해야 할 수 있습니다.

### 6-6. 컨테이너 상태 확인

```bash
# 실행 중인 컨테이너 확인
docker ps

# 로그 확인
docker logs caffit-backend
docker logs caffit-ai

# 실시간 로그 보기
docker logs -f caffit-backend
```

## 8. 문제 해결

### 컨테이너가 시작되지 않을 때

```bash
# 컨테이너 로그 확인
docker logs caffit-backend

# 컨테이너 재시작
docker restart caffit-backend

# 컨테이너 삭제 후 다시 생성
docker stop caffit-backend
docker rm caffit-backend
# 위의 docker run 명령 다시 실행
```

### 포트가 열리지 않을 때

1. AWS EC2 보안 그룹 확인
   - 인바운드 규칙에 8080, 5001 포트가 열려있는지 확인
2. EC2 방화벽 확인
   ```bash
   sudo firewall-cmd --list-ports
   ```

### 데이터베이스 연결 오류

1. MySQL이 실행 중인지 확인
   ```bash
   sudo systemctl status mysqld
   ```
2. 사용자 권한 확인
   ```bash
   mysql -u root -p
   SHOW GRANTS FOR 'caffit_user'@'localhost';
   ```

### Docker 권한 오류

```bash
# docker 그룹에 추가되었는지 확인
groups

# 다시 로그인
exit
ssh -i caffit-key.pem ec2-user@<퍼블릭-IP-주소>
```

## 10. 다음 단계 (선택사항)

### GitHub Actions로 자동 배포 설정

1. GitHub 저장소의 Settings > Secrets에 다음 추가:
   - `EC2_HOST`: EC2 퍼블릭 IP
   - `EC2_SSH_KEY`: .pem 파일 내용
   - `DB_URL`, `DB_USER`, `DB_PASSWORD`
   - `KAKAO_REST_API_KEY`, `OPENAI_API_KEY`

2. `.github/workflows/` 폴더의 파일들이 자동으로 배포를 처리합니다.

### 도메인 연결 (선택사항)

1. 도메인 구매 (예: Route 53)
2. EC2에 Elastic IP 할당
3. 도메인을 Elastic IP로 연결
4. SSL 인증서 설정 (Let's Encrypt 사용)
